Projective Decals

Table of Contents

  • 1. Preparing the resources

A decal is a texture projected onto existing geometry at runtime. Strategy games use decals to mark selected units with a circle on the ground; shooters use them for laser sights, bullet holes or shadow blobs.

This tutorial projects a decal onto a ring of Ogre heads and the floor beneath them, using a Ogre::Frustum as the projector.

What you will learn
  • how a Ogre::Frustum defines a texture projection,
  • how to add a projective decal pass to an existing material,
  • how to suppress the unwanted back projection with a filter frustum,
  • how to animate the projector.
Prerequisites
You can build an OGRE application and are familiar with Your First Scene and Lights, Cameras, and Shadows.

1. Preparing the resources

Copy the two textures decal.png and decal_filter.png into a directory listed in your resources.cfg, for example Media/materials/textures.

Note
Resource names are case sensitive on most platforms. Keep the lower case names used here, or adjust the code accordingly.
Warning
A decal texture must have a fully transparent border of at least one pixel. Otherwise texture clamping smears the outermost pixel row across the whole surface. Alternatively, use Ogre::TAM_BORDER (border in a script) together with a texture border colour of (0, 0, 0, 0) and let OGRE pad the image for you.

The floor uses a custom material. Add it to any .material script inside a registered resource location and make sure spacesky.jpg is available too:

```ini material Tutorial/SpaceFloor { technique { pass { texture_unit { texture spacesky.jpg } } } }
